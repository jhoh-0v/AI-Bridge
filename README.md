# AI Bridge

AI 활용을 처음 배우는 사람을 위한 한국어 업무 실습 서비스입니다. 목표는 상용 AI를 스스로 활용하는 것입니다. 웹은 진단·실습 연결·기록을 관리하고, Chrome 확장 프로그램은 실제 ChatGPT 옆에서 안내합니다.

[공개 서비스](https://ai-bridge-lab-bd5373.mystic-grape-2563.chatgpt.site/)

## 실습 코치 v4

- `/`, `/coach`: 단순화한 학습 홈, 프로필 진단, 확장 설치, 실제 기록 비교, 근거 검색.
- 실제 ChatGPT 화면 안내는 **엑셀 매출표 한 과제**부터 지원합니다. 기존 8개 분야는 `/practice-room`에 유지합니다.
- 첫 결과는 모든 수준에서 내용 가이드 없이 보관합니다. 이후 **초급: 추천 템플릿 + 항목별 작성 안내 / 중급: 템플릿으로 직접 요청 / 고급: 템플릿 직접 선택 + 검증 / 최종 평가: 안내 없는 새 과제**로 진행합니다.
- 버튼은 위치만 표시하며, 실제 첨부·작성·전송은 사용자가 합니다. 대화 내용을 읽거나 자동 수집하지 않습니다.
- 직접 선택한 XLSX를 기기에서 읽고 원자료, 행별 수식, 월별 합계, 전체 합계, 각 수량 변경 시 재계산을 검사합니다. 첫 결과를 임의로 생성하지 않으며 사용자 제출 기록임을 표시합니다.
- 독립 과제 5개 검사 + 확인 문항 2개 + 확장 내 도움 미사용으로 ‘엑셀 기초 과제 졸업’을 판정합니다. 외부 도움 사용, 실제 ChatGPT에서 생성했는지, 전반적인 AI 역량을 인증하는 제도가 아닙니다.
- 로그인 후 명시적으로 ‘기록 가져오기’를 누르면 제출 요청·워크북 셀 내용·해시·도움 기록을 계정에 보관합니다. 동일 ID의 다른 기록으로 덮어쓸 수 없습니다.

### 확장 프로그램 설치

`npm run build:coach`는 `outputs/ai-bridge-coach`의 압축 해제된 확장과 `public/downloads/ai-bridge-coach.zip`을 만듭니다. 웹 빌드도 이 명령을 포함합니다. Chrome 116 이상에서 `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 해당 폴더 선택. ChatGPT 페이지에서 AI Bridge 아이콘을 눌러 사이드 패널을 엽니다. 웹사이트도 Chrome에서 새로고침해야 진단 연동이 됩니다. 권한은 storage, sidePanel, activeTab 및 ChatGPT/본 Site의 콘텐츠 스크립트로 한정합니다.

`/coach-preview/index.html`은 동일 패널 코드의 **명시적인 안내 연습 화면**입니다. 실제 ChatGPT나 AI 생성 결과를 흉내 내어 제시하지 않습니다. 미리보기와 확장의 저장소는 분리되어 있습니다.

### RAG

`lib/coach/knowledge.mjs`의 출처·문단 ID·검토일·버전이 있는 15개 교육 문단을 BM25와 한국어 2글자 토큰으로 검색합니다. `retrieval.mjs`가 상위 근거를 질문에 결합하며, 확장에서 이를 복사해 실제 ChatGPT에 설명을 요청합니다. 검색 결과만 표시할 때는 AI 생성 설명으로 표시하지 않습니다. 공식 문서의 실시간 자동 수집이나 벡터 DB를 사용했다고 주장하지 않습니다.

`POST /api/bridge/coach/rag`는 키 없이 검색을 제공합니다. `generate:true` + 로그인 + 서버 API 키가 있는 경우에만 Responses API로 근거 기반 설명을 생성합니다. 반환 문단 ID가 실제 검색 결과에 있는지 검사하고, 근거가 없거나 호출·인용 검증이 실패하면 생성된 답변을 보여주지 않습니다. 계정당 UTC 날짜 기준 최대 20회, 실패 요청도 집계하며 자동 재호출하지 않습니다. **실제 유료 API 호출은 키 설정 미완료로 검증하지 않았습니다.**

검사 한계: 3MB·6시트·200행/시트·20열 이내 XLSX. 일반 셀 참조 및 지원 함수는 `extension/README.txt` 참조. 구조적 참조/미지원 함수는 실패 점수와 별도로 수동 확인 필요를 표시합니다. 사용자가 제출한 기록은 서비스 제공자의 생성 증명이 아니며, 전후 비교만으로 인과적 학습 효과를 입증하지 않습니다.

아래는 기존 `/practice-room`의 내부 생성 방식과 8개 분야에 관한 설명입니다.

## 회원가입과 맞춤 학습

- Sites의 **ChatGPT 계정 인증** 후 AI Bridge 프로필을 만듭니다. 자체 비밀번호를 받거나 저장하지 않습니다.
- 사용 목적, 관심 분야, 4개 상황 판단 문항을 받습니다. 문항은 목적·사실 확인·수치 검증·수정 요청을 다룹니다.
- 서버에서 진단하여 추천 순서와 가이드의 기본 열림 여부를 정합니다. 시작 수준에서는 구조화된 요청 작성 가이드를 먼저 보여 줍니다.
- 진단은 종합 역량 인증이 아닙니다. 실제 실습에서 남긴 근거와 새 과제의 수행 기록을 함께 확인합니다.
- 프로필 변경은 다음 실습부터 적용됩니다. 진행 중인 과제의 원자료와 조건은 보존합니다.
- D1에 사용자별 프로필·초안·생성 이력을 저장하고, R2 이미지도 로그인한 소유자만 받을 수 있습니다.

## 실제 기록으로 비교하기

첫 요청은 가이드 없이 사용자가 작성합니다. 첫 성공 결과를 수정하거나 더 나쁜 결과로 바꾸지 않습니다. 수정 단계에서는 확인 기준, 목적·대상·형식·조건 작성 가이드, 예시를 제공하고 사용자가 최종 요청을 편집합니다.

학습 전후에 같은 원자료, 모델 스냅샷, 시스템 지시, 파일 렌더러와 생성 설정을 사용합니다. 수정에는 직전 결과와 사용자의 후속 요청이 추가됩니다. 이미지 수정은 실제 이전 PNG를 Images Edits API에 전달합니다. 실패한 생성과 여러 수정 시도도 기록에 남습니다.

비교 화면과 JSON 기록에는 실제 요청, 원자료, 시각, 모델·설정, OpenAI 요청 ID, 원자료·결과 SHA-256, 수정 연결 관계, 사용자가 작성한 확인 근거를 담습니다. PPTX/XLSX/PNG 원본은 각 결과에서 내려받습니다. JSON에는 이미지 원본 바이트가 포함되지 않습니다.

이 기록은 해당 사용자의 변화와 과정을 보여 줍니다. 대조군 없는 개인 전후 비교만으로 서비스의 인과적 효과를 입증하거나 모든 사용자의 역량 향상을 보장하지는 않습니다. 슬라이드 수·수식·수치 대조는 자동 점검이고, 의미·사실·이미지 문구의 정확성은 원자료와 직접 대조합니다.

```powershell

node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_strange_ben_urich.sql
```

## OpenAI 연결 상태와 설정

**2026-10-29 현재: 서버 연동 코드는 구현했지만 API 키의 로컬 저장이 승인되지 않아 키를 생성·저장하지 않았습니다. 실제 유료 API 호출은 검증하지 않았습니다.** 키가 없으면 가입·진단·요청 저장은 사용할 수 있고 생성 버튼은 연결 필요 상태로 표시됩니다. 가짜 결과를 대신 보여 주지 않습니다.

`.env.example`은 변수 이름과 기본 설정만 담은 템플릿입니다. 로컬 비밀값은 `.dev.vars`, 배포 비밀값은 Sites 런타임 환경변수로 따로 설정합니다. 키는 채팅·프런트엔드·Git에 넣지 않습니다. 로컬 설정은 배포에 자동 복사되지 않습니다.

| 서버 변수 | 기본값 / 용도 |
| --- | --- |
| `OPENAI_API_KEY` | 실제 생성에 필요 |
| `OPENAI_TEXT_MODEL` | `gpt-5.4-mini-2026-03-17` |
| `OPENAI_IMAGE_MODEL` | `gpt-image-2.5-sunburst-2026-09-08` |
| `DAILY_TEXT_LIMIT` | 사용자별 UTC 하루 40회 |
| `DAILY_IMAGE_LIMIT` | 사용자별 UTC 하루 8회 |

실습 중 모델을 바꾸어 비교 조건을 바꾸지 않도록 최초 결과의 모델을 고정합니다. 텍스트는 Responses API의 Structured Outputs와 `store:false`, 이미지는 Images API를 사용합니다. 이미지 요청은 medium·1536×1024이고 반환된 PNG의 실제 크기를 기록합니다.

일일 한도는 성공·진행 중인 요청 수를 제한하는 서비스 보호 장치이며 금액 상한은 아닙니다. 실패나 중단으로 결과를 받지 못한 API 요청에도 사용료가 발생할 수 있습니다. 자동 유료 재시도는 하지 않습니다. 10분 이상 중단된 예약은 실패로 표시하며 새 요청은 사용자가 직접 실행해야 합니다.

## 구현과 배포

- `app/`: 반응형 화면, 가입·진단, 4단계 실습, 비교 스튜디오
- `lib/learning.mjs`: 8개 대표 과제·독립 과제·진단·추천
- `lib/service.mjs`: 계정별 저장, 단계 검증, 최초 결과 보존, 중복 호출 방지, 생성 한도
- `lib/openai.mjs`: 서버 전용 OpenAI 호출과 생성 영수증
- `lib/workbook.mjs`: 제한된 수식 계산과 원자료 대조
- `lib/exports.mjs`: PPTX·XLSX·PNG·JSON 다운로드
- `db/`, `drizzle/`: D1 스키마·마이그레이션
- `worker/`, `vite.config.ts`, `.openai/hosting.json`: Vinext·Cloudflare Workers·Sites 배포

PPT는 최대 10장의 편집 가능한 텍스트 기반 슬라이드입니다. 엑셀은 최대 4시트·시트당 100행·12열이며 사칙연산, 셀/범위 참조, SUM, SUMIF(값 일치), AVERAGE, MIN, MAX, COUNT, ROUND를 지원합니다. 지원하지 않는 수식은 오류로 표시합니다. 임의의 기존 PPT/XLSX 업로드·편집이나 사용자 파일 분석은 이 버전의 범위가 아닙니다.

기존 정적 프로토타입은 `/legacy/index.html`에 보존했습니다. 기존 브라우저 저장 키와 JSON 백업 기능을 유지하며 새로운 서버 계정 기록으로 임의 이관하지 않습니다. 이전 설명은 [legacy README](public/legacy/README.md)에 있습니다.
