# AI Bridge

ChatGPT, Gemini, Claude를 스스로 활용하는 방법을 연습하는 해커톤용 한국어 웹 프로토타입입니다.
AI Bridge는 업무 목적 정리, 요청 작성, 결과 확인, 후속 요청, 독립 실습을 안내합니다. 실제 업무는 사용자가 선택한 상용 AI에서 수행합니다.

[공개 데모 열기](https://ai-bridge-lab-bd5373.mystic-grape-2563.chatgpt.site/)

## 실행

프로젝트 폴더에서 다음 명령을 실행하고 http://127.0.0.1:4173 을 엽니다.

    python -m http.server 4173 --bind 127.0.0.1 --directory dist

별도 설치나 빌드가 필요하지 않습니다. 소스는 dist/index.html, dist/styles.css, dist/app.js 에 있습니다.

## 구성

- `dist/index.html`: 화면 구조
- `dist/styles.css`: 반응형 스타일
- `dist/app.js`: 연습 흐름, 예시 자료, 브라우저 내 기록
- `.openai/hosting.json`: Sites 배포 설정

## 구현된 흐름

- 매출 보고서, 문서 요약, 이메일 작성 과제 선택
- 상용 AI와 경험 수준 선택
- 업무 목적과 자료 설명을 바탕으로 요청 작성 및 편집
- 요청 복사, 상용 AI 새 창 열기, 정적 연습 자료 다운로드
- 사용자의 결과 확인 기록 및 후속 요청 작성
- 새 자료로 독립 실습, 힌트 사용 여부 구분
- 현재 브라우저의 학습 기록 저장과 텍스트 내려받기

## 프로토타입 범위

안내와 예시는 미리 작성된 콘텐츠이며 LLM API는 연결되지 않았습니다.
요청 문장은 사용자가 입력한 내용을 고정된 양식으로 묶습니다.
원본 자료를 업로드하거나 자체 계산, 데이터 분석, 정답 자동 판정을 수행하지 않습니다.
상용 AI를 여는 동작은 웹사이트 링크 이동이며 요청을 자동 전송하지 않습니다.
기록은 localStorage에 저장되며 원격 서버로 전송되지 않습니다.
실습 완료 표시는 사용자의 자기 확인 기록이며 역량이나 결과 정확성의 인증이 아닙니다.

화면의 외부 글꼴을 불러오지 못하면 브라우저의 기본 한국어 글꼴로 표시됩니다.
