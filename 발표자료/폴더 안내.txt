프로젝트 폴더 안내

AI bridge
- 앱·웹 소스, RAG 교육 자료, 테스트와 개발 설정을 모았습니다.
- 터미널에서 이 폴더로 들어가 npm run desktop으로 개발용 앱을 실행합니다.
- 로컬 실행 파일과 빌드 결과는 AI bridge\outputs\desktop 안에 보관하며 GitHub에는 포함하지 않습니다.

발표자료
- 시연영상: 전체 앱 화면이 보이는 최종 2분 30초 편집본입니다.
- 비포애프터: 같은 입력 자료, 기존 결과, 연도 선택 대시보드 XLSX·HTML입니다.
  HTML과 같은 이름의 XLSX는 같은 폴더에 두세요.
  원본 파일명은 삼성전자 재무제표이지만 파일 본문의 회사는 삼성E&A입니다.
- 프롬프트와코칭: 실제 전송한 비포·애프터 요청, 전체 발전 과정, 코칭 근거입니다.
  purpose·design 코칭은 최종 요청 이전, generation 코칭은 이후 기록입니다.
- 작업원본: 이전 시연본, 편집 중간 파일, 전체 세션·검증 기록, 편집 도구입니다.

보관 원칙
- 기존 파일은 삭제하지 않았습니다. 발표에 쓸 파일을 원본과 동일하게 별도로 모았습니다.
- 검증 기록 속 절대 경로는 당시 위치를 남긴 기록이므로 그대로 두었습니다.
- 이전 AIBridge\outputs\demo는 발표자료\작업원본으로 이동했습니다.
- 영상 원본 경로는 작업원본의 각 edit-manifest.json에 기록되어 있습니다.
- Git 저장소는 최상위 AIBridge 폴더입니다. 개발·빌드 명령은 AI bridge 폴더에서 실행하세요.
- GitHub에는 소스와 발표·검증 기록을 올리고, API 키·로그인 정보·의존성·다운로드한 편집 도구는 제외합니다.
