2. Chrome 주소창에 chrome://extensions 를 입력하세요.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드합니다'를 누르세요.
4. manifest.json이 있는 폴더를 선택하세요.
5. https://chatgpt.com 에서 퍼즐 아이콘 → AI Bridge를 눌러 코치를 여세요.
6. 웹사이트도 Chrome에서 새로고침하면 진단 수준과 완료 기록을 연결할 수 있습니다.

https://ai-bridge-lab-bd5373.mystic-grape-2563.chatgpt.site/coach
Chrome 116 이상. ChatGPT 계정과 파일 생성 기능의 이용 가능 여부는 별도입니다.

기능
실제 화면의 입력/첨부 위치 안내, 수준별 설명, 로컬 자료 검색과 근거 포함 질문 복사,
첫 결과 → 확인 → 수정 → 새 과제 실습, 제출 XLSX 수식 검사, 완료 JSON 내보내기.
확장은 AI API를 호출하지 않으며 API 키를 요구하지 않습니다.

데이터
ChatGPT 대화 내용이나 답변을 읽거나 수집하지 않습니다. 직접 붙여 넣은 요청과 답변,
직접 선택한 학습 파일의 셀 내용·해시, 도움 사용 이력만 기기에 보관합니다.
원본 XLSX 파일은 업로드하지 않습니다. 웹의 기록 가져오기를 누르면 학습 기록 안의
워크북 셀 내용과 요청이 로그인한 AI Bridge 계정에 전송됩니다.
가상 실습 자료만 사용하세요. 기기 저장소는 암호화된 금고가 아니며 확장 삭제 시 지워집니다.
실습 완료 후 JSON으로 기록을 보관할 수 있습니다.

검증 범위
6개 시트, 200행/시트, 20열, 3MB 이하 XLSX를 지원합니다.
산술·일반 셀 참조·SUM·SUMIF(일치 조건)·AVERAGE·MIN·MAX·COUNT·ROUND를 검사합니다.
표의 구조적 참조, 복잡한 함수, 매크로, 외부 참조는 자동 검사 대상이 아닙니다.
미지원 수식은 수학적으로 틀렸다는 뜻이 아닙니다. Excel에서 직접 확인하세요.
졸업은 제출 파일 5가지 조건, 확인 문항 2개, 확장 내 독립 실습 도움 사용 기록으로
판정하는 '엑셀 기초 과제' 결과이며 전반적인 AI 역량이나 외부 도움 미사용의 인증이 아닙니다.
실제 서비스에서 작성되었다는 인증도 아니며 사용자가 제출한 증거입니다.

UI 변경
버튼을 확실히 찾지 못하면 안내를 표시합니다. 실제 버튼은 사용자가 직접 누릅니다.
개발자 모드 확장 업데이트 후 ChatGPT/AI Bridge 페이지를 새로고침하세요.
웹 미리보기는 안내 위치를 연습하는 별도 화면이며 실제 ChatGPT나 AI 생성 화면이 아닙니다.
