# AI Bridge Windows 앱 · 0.13.0

실제 ChatGPT에서 직접 모델을 고르고, 자료를 첨부하고, 요청을 작성하며 배우는 Electron 앱입니다. 홈에서는 **샘플로 학습**과 **내 업무로 학습** 중 하나를 고릅니다. 진행 중인 학습이 있으면 **이어서 학습하기**를 함께 표시합니다. 학습자에게 개발 도구·확장 프로그램 설치나 API 키 입력을 요구하지 않습니다.

0.13.0에서는 첫 화면을 두 가지 학습 경로로 정리했습니다. 샘플로 학습을 선택하면 기존 8개 과정이 나오고, 내 업무로 학습은 기존 파일 업로드·작업 제안·직접 작업 입력으로 연결됩니다. 과정에는 Outlook·Word·PowerPoint·Excel·OneNote·ChatGPT 아이콘을 사용하며 파일을 앱에 포함해 오프라인에서도 표시합니다. 출처와 권리자는 `desktop/ui/assets/programs/sources.json`에 기록했습니다.

우측 상단 **내 프로필**에서 이름·하는 일·목적·관심 업무·4문항 시작 진단을 저장하고 수정할 수 있습니다. 목적과 관심 업무는 샘플 추천 순서에, 진단 결과는 새 실습의 기본 안내량에 반영됩니다. 이미 준비 중이거나 진행 중인 학습의 수준은 바꾸지 않습니다. 프로필은 이 PC에 저장되며 ChatGPT 로그인 계정 및 웹사이트 계정과 별도입니다.

0.12.0에서는 현재 실습 대화의 요청·답변 전체와 생성 파일을 연결하는 실시간 코치를 추가했습니다. 요청 전송, 답변 완성, 파일 내용 확인 때 RAG와 함께 다시 분석합니다. 모든 과정에서 문장·표·코드 답변만으로도 진행하며 독립 실습의 맞춤 피드백은 학습 완료 뒤에만 제공합니다.

## 오버레이

모델 메뉴 → 첨부 메뉴 → 준비한 파일 확인 → 입력창 → 전송 버튼 → 실제 답변·파일 → 결과 확인 → 수정 → 독립 실습 순서로 안내합니다. 프롬프트와 원자료를 자동 입력하거나 전송하지 않습니다.

초급은 구체적인 행동과 이유, 중급은 조건을 생각할 질문, 고급은 검증 기준으로 안내합니다. 오버레이에는 지금 할 일 하나를 먼저 표시하고, 펼쳐서 현재 목표·다음 학습 순서·실제 대화 인용·RAG 근거를 봅니다. 독립 실습은 기록만 하며 AI 호출과 피드백 표시를 차단합니다. 학습 마치기를 누른 후 독립 대화를 포함해 회고합니다. 기본 과정은 새 샘플, 내 자료 과정은 같은 파일과 마지막 목표로 혼자 다시 수행합니다.

파일 선택 이벤트와 실제 업로드 완료를 관찰해 SHA-256과 첨부 표시를 함께 확인하고, 새 사용자 메시지가 대화에 나타나야 전송을 기록합니다. 이름에 다운로드 번호가 붙어도 내용이 일치해야 인정하며, 업로드 실패나 다른 자료를 성공으로 기록하지 않습니다. 관찰한 답변의 파일 선택과 실제 다운로드를 연결합니다. 미리보기 내부에서 클릭이 전달되지 않으면 현재 실습 대화에 표시된 파일명과 일치하는 답변이 하나일 때만 연결합니다. 여러 답변에 같은 파일명이 있으면 임의로 골라 연결하지 않습니다. 같은 요청에서 동일한 파일을 다시 내려받아도 AI 입력에서는 중복을 제거합니다.

## RAG

교육 문단 87개: 8개 업무별 8개씩 64개, 기존 엑셀 자료 15개, 공통 원칙 8개입니다. AI Bridge가 작성한 교육 노트이며 분야·단계·수준·출처·버전을 포함합니다. 일부는 Microsoft·OpenAI·GOV.UK 문서를 참고하며 기관 공인 교재나 검증된 효과 데이터로 표시하지 않습니다.

- 원문: lib/coach/knowledge-library.mjs, lib/coach/knowledge.mjs
- 검색: lib/coach/retrieval.mjs의 BM25 + 한국어 2글자 토큰. 별도 임베딩 모델·벡터 DB는 없습니다.
- 수정 안내: 분야·수준·단계에 맞는 교육 문단을 검색해 표시합니다.
- 맞춤 커리큘럼: desktop/ai-curriculum.mjs가 파일 내용과 검색 근거를 Codex CLI에 전달합니다.
- 대화 코치: desktop/dialogue-coach.mjs가 실습의 모든 관찰된 요청·완료 답변·읽은 파일 내용·원자료와 RAG 문단을 함께 전달합니다. 최신 요청에 따라 분야를 가로질러 검색하며 목표·확인 기준·다음 학습 단계를 갱신합니다. 인용은 실제 대화/자료의 문자열과 대조하고, 오류 단정에는 요청/원자료와 답변/파일 양쪽 근거를 요구합니다.
- 이전 버전의 제출 후 설명은 보관하며, 새 대화 코치는 같은 결과에 중복 호출하지 않습니다.

JSON 스키마로 생성한 응답의 단계·열·인용 ID를 검증합니다. 실제 제공자·응답 ID·모델·사용량·입력 해시·근거 ID는 실습 흐름에 보관합니다. 커리큘럼은 기기당 UTC 날짜 기준 20회, 대화 코치는 80회입니다. 실패도 집계하며 자동 재시도하지 않습니다. 같은 입력의 분석은 재사용하고 최신 사건만 직렬 처리합니다. 이전 대화의 늦은 AI 응답은 버립니다. 앱이 닫힌 중단 상태는 오류로 표시하며 직접 다시 분석할 수 있습니다.

## 실제 비포·애프터와 검사 범위

처음 완료된 답변은 별도로 고정하고 실제 요청·답변·파일을 보관합니다. 수정 결과의 목표와 확인 기준도 제출 시점에 고정합니다. 목표가 바뀌면 서로 다른 과제의 점수로 학습 향상을 단정하지 않는다고 안내합니다. 이전 버전에서 보관한 비포·애프터는 덮어쓰지 않습니다. 비교 화면에서 요청·답변을 펼쳐 보고 실제 결과 파일을 열 수 있습니다. 파일을 열기 전 보관 당시 해시와 대조합니다. 처음부터 좋은 결과가 나와도 그대로 표시합니다.

대화 학습은 실제 결과의 존재와 직접 확인할 내용 기준을 나눕니다. AI가 업무 정확성이나 졸업을 자동 통과시키지 않습니다. 기존 고정 과제의 수식 검사와 과거 증거는 유지합니다.

생성된 파일 링크/미리보기도 답변으로 기록합니다. 학습자가 ChatGPT에서 직접 내려받으면 원래 요청에 연결해 내용을 읽고 AI 피드백을 갱신합니다. 늦게 받은 이전 요청의 파일도 올바른 요청에 연결합니다. XLSX는 3MB·6시트·시트당 200행·20열, DOCX/PPTX는 추출 텍스트, TXT/MD/CSV/JSON은 60,000자까지, PNG/JPEG/WebP는 20MB까지 읽습니다. 이미지는 실제 픽셀을 Codex 이미지 입력으로 전달합니다(한 실습 최대 6개). 엑셀의 실제 앱 재계산이나 PPT/문서의 배치·서식 검사는 실행하지 않습니다. PDF와 지원 범위 밖의 파일은 생성 사실만 기록하고 내용을 읽지 못했다고 표시합니다. 다운로드 전에는 파일 내용을 분석했다고 말하지 않습니다.

관찰 범위는 앱에서 현재 실습에 연결한 ChatGPT 대화입니다. 다른 계정 대화나 다른 탭을 수집하지 않습니다. 재개할 때 현재 대화의 화면에 표시된 앞부분을 복구하며, 이전에 관찰한 메시지는 화면에서 사라져도 로컬에 남깁니다. 한 실습 요청 100개, 메시지당 60,000자, 모델 입력 원자료·대화·파일 합계 320,000자 이내입니다. 초과분을 몰래 잘라 전체 분석으로 표시하지 않고 안내합니다. 제출 비교용 답변은 12,000자, 전체 관찰 기록은 별도 흐름 파일에 보관합니다.

첫 요청 전에도 목표와 첨부 방법은 안내하므로 무개입 대조 실험이나 정량적 학습 효과의 증명으로 해석하지 않습니다.

## 생성 연결: Codex CLI

이 PC에서 이미 ChatGPT로 로그인한 Codex CLI를 사용합니다. 모델은 gpt-6-luna이며, API 잔액 대신 해당 계정의 Codex 사용량·크레딧이 적용됩니다. 커리큘럼과 맞춤 설명을 실제로 생성하며, 학습자의 업무 결과물은 계속 실제 ChatGPT에서 직접 만듭니다. 학습 화면에서 CLI 설치·명령어·API 키 입력을 요구하지 않습니다.

desktop/codex-coach.mjs는 공식 Codex 실행 파일을 찾아 로그인 상태를 확인합니다. 각 생성은 임시 폴더의 codex exec로 실행하며, 사용자 설정·추가 도구·셸·앱·MCP·웹 검색을 사용하지 않습니다. ChatGPT 로그인 방식을 지정하고 API 키를 하위 프로세스에 전달하지 않습니다. 자료·대화·교육 근거를 표준 입력으로 보내고, 검증한 결과 이미지는 임시 복사본을 --image로 첨부합니다. 종료 시 임시 파일을 지우며 출력 스키마를 검사합니다. 이미지 옵션은 공식 문서 https://learn.chatgpt.com/docs/developer-commands?surface=cli 및 설치된 codex exec --help로 확인했습니다. 응답 제한은 90초이며, 실행 실패나 사용 한도를 실제 오류로 표시합니다. API로 자동 전환하지 않습니다.

이 구성은 Codex가 설치되고 로그인된 이 PC에서 실행하는 시연용입니다. 다른 PC에서는 운영자가 Codex 로그인과 사용 가능 모델을 준비해야 합니다. 공개 웹 서비스나 여러 사용자가 공유하는 배포에는 별도의 인증된 서버 연결이 필요합니다.

## API 키 설정 표시

2026-10-30: Codex의 대화형 승인을 켠 뒤 저장 확인이 정상 승인되었습니다. 새 키를 승인한 루트 .dev.vars에 저장했습니다. 당시 실제 Responses API 요청은 429 / credit_balance_exhausted / insufficient_quota를 반환했습니다. 현재 생성에는 이 키를 사용하지 않으며 화면에도 ‘API 키 설정 완료 · 현재 생성에는 사용하지 않음’으로 표시합니다.

운영자 연결 명령 node scripts/connect-desktop.mjs는 승인·저장된 루트 .dev.vars의 위치만 %APPDATA%/AI Bridge/operator-ai.json에 등록합니다. 배포 EXE도 재실행할 때 이 위치에서 OPENAI_API_KEY와 선택적인 OPENAI_TEXT_MODEL만 읽습니다. 실행 환경에 키가 이미 있으면 이를 우선합니다. 환경 파일을 셸 코드로 실행하지 않으며, 작업 폴더 밖 경로·연결된 파일·잘못된 설정을 거부합니다. 키를 앱 기록·renderer·ChatGPT 페이지·배포 파일에 복사하지 않습니다. 다른 사용자에게 배포하기 위한 인증된 공용 코치 서버는 별도 구축이 필요합니다.

## 실행과 기록

배포: outputs/desktop/AI-Bridge-0.13.0-Windows.exe. 앱의 실습 화면에는 본인의 ChatGPT 계정으로 로그인합니다. 코치 생성은 이 PC의 Codex 로그인을 사용합니다. 기능·이용 한도는 실제 계정에 따르며 현재 빌드는 코드 서명 전 단계입니다.

개발: npm ci → npm ci --prefix desktop → npm run desktop. 배포: npm run package:desktop.

기록은 %APPDATA%/AI Bridge 아래 learning.json, practice-flows.json, downloads.json에 저장됩니다. 직전 학습 기록의 .bak을 유지하고 기존 기록과 로그인 세션을 삭제하지 않습니다. --manual-check 개발 실행은 실제 ChatGPT를 사용하면서 학습 기록을 manual-validation/에 분리합니다. QA fixture는 배포 패키지에서 제외합니다.

## 검증

자동 테스트 147개를 통과했습니다. 8개 과정의 4단계·복원·원자료 비교, 새 샘플, Office 텍스트 추출, 업무별 RAG 검색, 동의·구조·근거 검증, 환경 변수 범위·연결 복원·경로 제한, Codex 제공자 기록 및 API 자동 전환 차단을 포함합니다. 직접 입력한 작업의 보존과 업로드 완료·실패·이전 요청 지연·파일 내용 대조, 실시간 대화·결과 파일의 연결, 독립 실습의 피드백 차단도 검사합니다. 단위 테스트의 생성 응답은 모의 응답입니다.

0.12.0에서는 직접 입력한 작업으로 실제 Codex 커리큘럼을 생성하고, 배포 앱의 입력란·버튼·생성 결과까지 확인했습니다. 실제 ChatGPT에 샘플과 동일한 내용의 파일을 다른 이름으로 첨부했을 때 요청 작성 안내로 전환되고, 첨부 제거 시 준비 상태가 해제되는 것도 확인했습니다. 상세 검증 기록은 outputs/desktop/validation-0.12.0.json과 validation-live-custom-0.12.0.json입니다.

별도로 가상 문의 현황 자료를 실제 Codex에 전달해 작업 3개·각 4단계 커리큘럼과 근거를 생성했고, 가상 결과에 대한 맞춤 피드백도 실제 생성했습니다. outputs/desktop/codex-curriculum-live-check.json과 codex-feedback-live-check.json에 실제 응답 ID와 사용량을 보관합니다. 가상 자료를 사용한 기능 검증이며 학습 효과나 사용자의 학습 성과로 표시하지 않습니다.

앱 화면에서도 가상 파일 선택 → 미리보기 → 전송 동의 → 실제 Codex 작업·커리큘럼 생성 → 선택 → 실제 ChatGPT의 맞춤 목표와 모델 선택 오버레이까지 확인했습니다. 첫 시도에서 제안 검증 실패를 발견해 생성 스키마를 실제 자료 항목과 업무별 검색 근거로 제한했고, 수정 후 성공했습니다. 선택한 실제 커리큘럼과 생성 기록은 outputs/desktop/codex-curriculum-ui-check.json에 있습니다. 이번 변경에서 새로 수행한 내 자료 실습은 오버레이 시작까지이며, 학습자의 실제 결과 생성·수정·독립 실습 전 과정은 재실행하지 않았습니다.

버전별 실제 화면 검증 범위는 outputs/desktop/validation-*.json에 기록합니다. 상용 AI의 UI 변경으로 관찰이 실패할 때 성공했다고 표시하지 않습니다.

0.13.0은 147개 회귀 테스트와 데스크톱 빌드를 통과했습니다. 실제 배포 앱에서 홈의 두 경로, 8개 샘플 목록과 아이콘, 샘플 미리보기, 내 업무 준비, 뒤로 가기, 프로필 생성 화면을 확인했습니다. 별도 QA 저장소에서 이름·목적·관심 업무를 수정하고 4문항 진단을 저장해, 추천 순서 및 다음 실습의 기본 수준에 반영되는 것을 확인했습니다. 사용자 앱은 기존 진행 단계와 이어서 학습하기를 보존한 새 홈으로 열어 두었습니다. 상세 기록은 outputs/desktop/validation-0.13.0.json입니다.
