# AI Bridge

ChatGPT, Gemini, Claude를 스스로 활용하는 방법을 연습하는 한국어 웹 앱입니다.
업무 목적 정리, 요청 작성, 근거 확인, 후속 요청 실행, 개선 결과 비교, 독립 실습을 안내합니다. 실제 AI 실행은 사용자가 선택한 서비스에서 직접 수행합니다.

[공개 데모 열기](https://ai-bridge-lab-bd5373.mystic-grape-2563.chatgpt.site/)

## 실행

프로젝트 폴더에서 다음 명령을 실행하고 http://127.0.0.1:4173 을 엽니다.

    python -m http.server 4173 --bind 127.0.0.1 --directory dist

별도 설치나 빌드가 필요하지 않습니다. ES 모듈을 사용하므로 HTML 파일을 직접 열지 말고 위 로컬 서버로 실행합니다.

자동 테스트는 Node.js 20 이상에서 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

    npm test

또는 `node --test`를 사용할 수 있습니다.

## 구성

- `dist/index.html`, `dist/app.js`: 페이지와 모듈 진입점
- `dist/styles.css`: 반응형 배치, 읽기 쉬운 글자 크기와 대비, 키보드 포커스
- `dist/js/content.js`: 과제·수준별 자료, 기준 답안, 안내 문구
- `dist/js/state.js`: 순수 상태 전이, 단계별 검증, 요청 변경 이력
- `dist/js/storage.js`: 저장·복원 스키마 검증, 이전 버전 이관, 저장 실패 처리
- `dist/js/feedback.js`: 요청 구성과 자기 확인에 따른 안내
- `dist/js/views.js`, `dist/js/ui.js`: 화면과 공통 UI
- `dist/js/controller.js`: 사용자 입력, 자동 저장, 다운로드·복원 연결
- `dist/js/records.js`: 전체 과정을 포함한 개별 TXT 기록
- `test/state.test.js`: 데이터 보존, 단계 검증, 저장·복원과 렌더링 회귀 테스트
- `test/controller.test.js`: 백업 선택·취소·복원 이벤트, 자동 저장과의 충돌, 파일 읽기 순서 및 저장 실패 회귀 테스트
- `.openai/hosting.json`: Sites 배포 설정

## 구현된 흐름

- 매출 보고서, 문서 요약, 이메일 작성 과제 선택
- 상용 AI와 기초·응용·심화 수준 선택; 심화에서는 독립 실습부터 시작 가능
- 업무 목적과 자료 설명을 바탕으로 요청 작성 및 편집
- 요청 복사, 상용 AI 새 창 열기, 정적 연습 자료 다운로드
- 자료를 화면에서 읽기, 다운로드 → 요청 복사 → AI 실행 → 복귀 안내
- 과제별 기준 답안과 원자료 근거 대조; 미확인 항목은 그대로 기록
- 후속 요청 실행 확인, 개선된 답변과 처음 답변 비교, 개선 내용 성찰
- 수준별 새 과제로 독립 실습, 3단계 힌트와 기준 답안 열람 내역 구분
- 과제를 전환해도 각각의 초안·도구·단계 보존
- 준비 내용 변경 시 요청문 갱신 또는 직접 편집한 요청 유지 선택
- 요청·AI 변경 시 재실행 요구; 이전 답변과 확인 내용은 이력에 보관
- 최초 요청, 답변, 확인 근거, 후속 요청, 개선 결과, 독립 실습을 함께 기록
- 개별 TXT 기록 및 전체 JSON 백업·복원

## 저장과 복원

`aibridge-state-v2` 키에 과제별 초안과 완료 기록을 저장합니다. 300ms 지연 저장 후 저장 상태를 표시하며, 페이지 이탈·탭 숨김에서도 남은 변경을 저장합니다. 최근 30개 제한은 없으며 브라우저 저장 용량 한도까지 유지합니다. 용량 또는 접근 권한 문제로 저장할 수 없으면 경고와 재시도·전체 백업을 제공합니다.

기존 `aibridge-prototype-v1` 기록은 처음 실행할 때 이관하고 기존 키의 원본은 유지합니다. 이전 버전에서 저장하지 않았던 답변 등은 복원할 수 없으므로 미기록으로 표시합니다. 손상되었거나 지원하지 않는 저장 내용은 자동 덮어쓰지 않습니다. 다른 창에서 데이터가 바뀌어도 저장을 멈추고 사용자에게 알려줍니다.

나의 학습 기록 → 전체 백업 받기로 초안과 기록 전체를 JSON 파일에 보관합니다. 복원할 JSON 파일(20MB 이하)을 선택하면 기록·초안 개수와 대체 안내가 나타납니다. 확정하면 현재 내용의 백업 다운로드를 먼저 시작한 뒤 복원합니다. 다운로드는 브라우저 설정에 따라 막힐 수 있으므로 파일 저장 여부를 확인해야 합니다. 파일 구조 검증이나 저장에 실패하면 현재 상태를 유지합니다. TXT 파일은 읽기용이며 복원용 파일이 아닙니다.

## 프로토타입 범위

안내와 기준 답안은 미리 작성된 콘텐츠이며 LLM API는 연결되지 않았습니다. 확인 항목에 따라 다음 확인 방법을 안내하지만, 사용자가 붙여넣은 AI 답변을 자동 채점하지 않습니다. 요청 구성 안내는 입력 여부를 확인하며 내용 품질 점수가 아닙니다.
요청 문장은 사용자가 입력한 내용을 양식으로 묶고 직접 편집할 수 있습니다.
사용자의 원본 업무 자료를 업로드하거나 자체 데이터 분석을 수행하지 않습니다. 백업 JSON 가져오기는 브라우저 안에서만 처리합니다.
상용 AI를 여는 동작은 웹사이트 링크 이동이며 요청을 자동 전송하지 않습니다.
기록은 localStorage에 저장되며 원격 서버로 전송되지 않습니다.
실습 완료, 힌트 사용, 확인 결과는 사용자의 자기 확인 기록이며 역량이나 결과 정확성의 인증이 아닙니다.

## 검증

자동 테스트는 과제 전환·재시작 후 초안 보존, 요청 갱신의 명시적 선택, 재실행 요구, 단계 건너뛰기 방지, 후속 요청과 전체 기록 보존, 30개 초과 기록, 3과제×3수준, 기준 CSV 수치, 긴 입력, JSON 왕복 복원·손상 거부, 저장 실패·재시도, 이전 기록 이관, 사용자 입력의 HTML 이스케이프를 확인합니다.

컨트롤러 테스트는 실제 이벤트 처리 코드를 메모리 DOM·저장소 어댑터로 실행합니다. 복원 전 현재 데이터 백업, 선택 취소, 잘못된 파일 거부, 복원 후 지연 저장·페이지 이탈·재로딩, 저장 실패 후 재시도, 여러 파일의 읽기 완료 순서가 바뀌는 상황을 확인합니다. `AIBRIDGE_TEST_BACKUP` 환경 변수에 JSON 파일 경로를 지정하면 해당 파일로 복원 검증을 실행합니다. 파일은 읽기만 하며, 실제 브라우저의 저장 데이터는 변경하지 않습니다. 이 테스트는 실제 화면·파일 선택창·다운로드 권한 검증과 별개입니다.

브라우저에서 실제 AI 서비스를 호출할 필요 없이 표시를 붙인 가상 답변으로 UI를 확인할 수 있습니다. 이는 AI 답변의 품질 평가를 대신하지 않습니다. 사용자 테스트 시에는 처음 요청 실행까지 막힌 위치, 근거를 찾는 과정, 후속 요청의 개선 내용, 새 과제를 도움 없이 진행할 수 있는지를 관찰합니다.

모바일(390px 및 320px), 확대(200%), 키보드만으로 이동, 잘못된 백업 선택·취소·복원도 배포 전에 확인합니다. 검증을 위해 만든 기록은 테스트 전 JSON 백업을 복원해 정리할 수 있습니다.

화면의 외부 글꼴을 불러오지 못하면 브라우저의 기본 한국어 글꼴로 표시됩니다.
